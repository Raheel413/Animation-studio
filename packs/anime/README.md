# Anime (planned, code-only)

**Ceiling: 4/10.** The owner chose code-only, so there are no AI-generated keyframes. Real anime character animation is hand-drawn; code cannot reproduce it.

What code can do well is anime *staging* around simple cel-shaded vector characters: speed lines, impact frames, dramatic pans across a still, parallax backgrounds, eye close-ups, colour-flash cuts, held poses with moving hair or cloth via path wobble.

Honest use: short action beats and title sequences, not a 10-minute anime episode. Revisit the code-only decision if a full anime look matters; with AI keyframes the ceiling rises to about 6-7/10.
