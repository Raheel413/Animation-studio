# Cut-out 2D characters (planned)

**Ceiling: 6/10.** Rigged puppet characters (head, torso, upper and lower limbs as separate SVG parts on pivots) animated in Remotion with pose libraries and eased interpolation between poses: walk cycles, gestures, lip-flap synced to voiceover word timings.

Cannot do: fluid hand-drawn frame-by-frame animation, smears, or full turnarounds.

Build order: 1) rig format (JSON pivots), 2) pose library and pose-to-pose tweening, 3) walk cycle, 4) mouth shapes from ElevenLabs character timings, 5) one 60 s test film through the quality gates.
